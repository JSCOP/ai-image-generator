사용 가능 모델

    저장된 이미지는 유지됩니다. 다시 시작하려면 open-image-studio.cmd를 실행하세요.

    생성 설정

    해상도·품질 안내

    선택한 해상도는 최종 저장 크기입니다. 모델 원본과 다르면 자르기·리샘플링으로 맞춥니다.

    품질 옵션의 해석은 제공자마다 다릅니다.

    프롬프트 작성

    간단한 설명이나 Positive 중 하나만 입력해도 됩니다.

    프롬프트 입력 안내

    Negative는 회피 지시로 전달됩니다. 가중치 표기는 그대로 전달되지만 모델이 반영하지 않을 수 있습니다. 샘플러·스텝·가이던스는 지원하지 않습니다.

    텍스트와 모델 설정은 이 브라우저에 초안으로 저장합니다. API 키와 참조 파일은 초안에 저장하지 않습니다.

    참조 이미지 최대 4장 · 장당 10MB

    이미지를 선택하거나 여기로 끌어놓으세요
