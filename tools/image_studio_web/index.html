사용 가능 모델 상태 (카탈로그 선택과 별개)

연결 확인 후에 표시됩니다. 아직 확인 전이면 “미확인”으로 표시됩니다.

    서버 관리

    로컬 서버만 멈춥니다. 생성된 이미지는 삭제되지 않습니다. 종료 후에는 open-image-studio.cmd를 다시 실행하세요.

    모델 · 해상도 · 품질

    최종 파일은 요청한 해상도로 정확히 저장됩니다(필요시 자르기/리샘플링). 모델의 네이티브 출력 크기와 다를 수 있습니다.

    품질 옵션의 해석은 제공자마다 다르며 결과물을 보장하지 않습니다.

    프롬프트

    메인 프롬프트 또는 Positive 중 하나는 반드시 입력하세요. Negative는 피하고 싶은 요소를 적는 칸입니다.

    작성 안내

    Negative는 뒤에 덧붙는 회피 지시입니다. 가중치 표기는 그대로 전달되며 반영되지 않을 수 있습니다.

    샘플러·스텝·가이던스 설정은 없습니다.

    참조 이미지 (최대 4장 · 장당 10MB)

    클릭하거나 파일을 여기로 끌어다 놓으세요

    이미지 파일만 가능합니다.

      모델을 바꿔도 첨부된 참조는 절대 자동 삭제하지 않습니다. 지원하지 않는 모델에서는 생성 버튼이 막히고 안내가 표시됩니다.

      입력 초안(텍스트·모델 설정)은 이 브라우저에만 저장됩니다. API 키는 저장하지 않습니다.

      왼쪽에서 프롬프트를 입력하고 [한 장 생성]을 누르세요. 생성된 이미지는 여기에 크게 표시됩니다.

      Positive

      다시 쓰기는 텍스트·모델·해상도·품질만 복사합니다. 저장된 참조 파일은 불러오지 않으므로 필요하면 직접 다시 첨부하세요.

      최근 작업

      페이지를 새로고침해도 서버에 저장된 작업 기록이 다시 표시됩니다. 생성 중 새로고침하면 진행 확인만 이어가고, 자동 재생성하지 않습니다.

      저장 위치: 확인 중…

        아직 생성 기록이 없습니다.

        안내
        • 최종 크기가 다르면 서버가 자르기/리샘플링으로 맞춥니다. 결과 카드의 “최종” 치수가 실제 파일 크기입니다.
        • 중단/새로고침 후에도 성공한 이미지는 작업별로 보존되며, 오류 메시지는 해당 작업에 함께 표시됩니다.
        • 서버 콘솔의 Ctrl+C로 종료합니다. 결과 파일은 저장 위치에 그대로 남습니다.
